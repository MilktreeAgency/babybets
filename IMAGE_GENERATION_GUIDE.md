Now that Nanobanana Pro MCP is configured, you can request on-brand images for your competitions!

```

Prize: [PRIZE NAME]

Description: [Brief description]

```

## 🎨 Quick Reference by Category

### 💰 Cash Prizes
**Style**: Clean stacks of pound notes, financial relief imagery, family home context
**Colors**: Teal/green tones, professional
**Mood**: Security, relief, prosperity

**Example request:**
```
Generate a competition image for BabyBets:
Prize: £10,000 Tax-Free Cash
Category: Cash
Description: Life-changing money for a family, showing neatly arranged British pound sterling notes with soft teal and cream tones. Professional, trustworthy, aspirational mood.
```

## ✨ Pro Tips

1. **Be specific**: Mention exact products when possible (e.g., "Bugaboo Fox 5" not just "stroller")
2. **Set the mood**: Use emotional descriptors (magical, serene, joyful, aspirational)
3. **Mention lighting**: "Natural light", "golden hour", "soft lighting" helps a lot
4. **Include context**: "In a modern nursery", "family home setting", etc.
5. **Reference brand colors**: Include "teal and cream tones" or "peach accents"
6. **Specify composition**: "Leave space in top-left for badge overlay" if needed

---

## 🚀 Example Workflow

### When you need a new competition image:

1. **Open chat with Cursor AI**
2. **Use the template** above
3. **Review the generated image**
4. **Request tweaks** if needed (lighter, more teal, different angle, etc.)
5. **Save to project** when satisfied

### Example conversation:
```
You: "Generate a competition image for BabyBets for a £5,000 Emergency Fund cash prize. Show British pound notes in a family-friendly, trustworthy style with teal and cream tones."

AI: [Generates image using Nanobanana Pro MCP]

You: "Can you make it warmer and add a subtle piggy bank in the background?"

AI: [Refines the image]
```

- Verify your Gemini API key is active and has quota
- Try a simpler prompt first to test the connection
- Check the Cursor console for any MCP errors
